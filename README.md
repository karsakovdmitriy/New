# Sports Training Management MVP: Руководство по запуску и отладке

Это SaaS-платформа для тренеров и спортивных студий, построенная на стеке **Next.js + Supabase + Tailwind**. Данное руководство поможет вам развернуть проект с нуля и настроить все интеграции.

---

## 1. Предварительные требования

Перед началом убедитесь, что у вас установлены:
- **Node.js** (v18+)
- **NPM** или **Bun**
- **Supabase CLI** (опционально, для локальной разработки)
- Аккаунт на **Supabase.com** и **Vercel.com**
- **Telegram Bot** (созданный через @BotFather)

---

## 2. Настройка базы данных (Supabase)

1. **Создайте проект:** В консоли Supabase создайте новый проект.
2. **Примените схему:**
   - Перейдите в раздел **SQL Editor**.
   - Скопируйте содержимое файла `supabase/schema.sql` из этого репозитория и выполните его.
   - Это создаст таблицы (`profiles`, `workouts`, `slots`, `bookings`, `telegram_settings`), типы ролей, RLS-политики и триггеры для синхронизации пользователей и проверки вместимости.
3. **Настройте Auth:**
   - В разделе **Authentication -> Settings** убедитесь, что включена регистрация по Email.
   - (Опционально) Отключите подтверждение почты для быстрого тестирования MVP.

---

## 3. Локальный запуск Next.js

1. **Клонируйте репозиторий.**
2. **Установите зависимости:**
   ```bash
   npm install
   ```
3. **Настройте переменные окружения:** Создайте файл `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=ваш_url_проекта
   NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_anon_key
   ```
4. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```
   Проект будет доступен по адресу `http://localhost:3000`.

---

## 4. Настройка Telegram уведомлений

Интеграция работает через **Supabase Edge Functions**.

1. **Установка токена:** В консоли Supabase перейдите в **Settings -> API** и добавьте секрет для функций:
   ```bash
   supabase secrets set TELEGRAM_BOT_TOKEN=ваш_токен_бота
   ```
2. **Развертывание функции:**
   Используйте Supabase CLI для деплоя функции `telegram-notify`:
   ```bash
   supabase functions deploy telegram-notify
   ```
3. **Настройка Webhook:**
   Чтобы функция срабатывала при новых записях, создайте Database Webhook в Supabase Dashboard (**Database -> Webhooks**):
   - **Table:** `bookings`
   - **Events:** `INSERT`
   - **Target:** HTTP Request (POST) к URL вашей Edge Function.

---

## 5. Деплой на Vercel

1. Подключите ваш GitHub репозиторий к Vercel.
2. Добавьте те же переменные окружения (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`).
3. Vercel автоматически соберет и развернет проект.

---

## 6. Отладка (Debugging)

### Проверка базы данных и RLS
Если данные не отображаются или не сохраняются:
- Проверьте **RLS Policies** в Supabase. Убедитесь, что `auth.uid()` совпадает с `id` в таблице `profiles`.
- Посмотрите логи в **Database -> Webhooks** (раздел History), чтобы увидеть, уходят ли запросы к Telegram.

### Проверка Edge Functions
Если уведомления в Telegram не приходят:
- Перейдите в **Functions -> telegram-notify -> Logs**.
- Ищите ошибки доступа (401/403) или сетевые ошибки fetch к API Telegram.
- Убедитесь, что у тренера в таблице `telegram_settings` указан корректный `chat_id`.

### Проверка фронтенда
- Используйте Browser DevTools (вкладка **Network**), чтобы проверить запросы к Supabase.
- Проверьте вкладку **Console** на наличие ошибок гидратации или Auth-ошибок.

## 8. Сценарий тестирования MVP

1. **Регистрация тренера:** Создайте аккаунт, в профиле привяжите свой Telegram Chat ID (получите его у бота).
2. **Создание тренировки:** Перейдите в панель тренера и создайте тренировку "Бадминтон", цена 1000.
3. **Добавление слота:** Зайдите в тренировку и создайте слот на завтра, вместимость 2 человека.
4. **Регистрация клиента:** Выйдите и создайте новый аккаунт клиента.
5. **Запись:** Найдите тренировку в каталоге и запишитесь.
6. **Проверка уведомления:** Тренер должен моментально получить сообщение в Telegram.
7. **Проверка лимита:** Попробуйте записать более 2-х человек на тот же слот — база данных должна вернуть ошибку.
8. **Вход администратора:** Зайдите под `admin@sports-mvp.com`, чтобы проверить права доступа.

---

**Важно:** Для MVP мы используем упрощенную схему. В будущем рекомендуется заменить `alert()` на `toast notifications` и внедрить полноценную систему миграций через Supabase CLI.
